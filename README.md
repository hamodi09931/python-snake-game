# Python Snake Game

A simple Snake game built with Python's Turtle graphics module.

## Features
- Arrow key controls
- Random food generation
- Score tracking
- Wall collision detection
- Self-collision detection
- Simple and clean game loop

## Requirements
- Python 3.8 or newer

## How to run

```bash
python main.py
```

## Controls
- Up: Arrow Up
- Down: Arrow Down
- Left: Arrow Left
- Right: Arrow Right

## Project files
- `main.py` - main game loop
- `snake.py` - snake logic
- `food.py` - food spawning
- `score.py` - scoring and game over screen
- `rong.py` - collision handling logic
